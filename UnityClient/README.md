# Tower of Chaos - Unity 6 client (Phase-0 vertical slice)

Grey-box slice: one hero runs a whole procedurally generated tower. **All rules live in `Core/`** (pure C#); the Unity scripts only feed input and draw.

> **Honest status:** this project was assembled on a machine **without Unity installed**. The scripts compile against the real Core library and a stub of
> the Unity API (`Core/tools/UnityCompileCheck`), which catches typos and wrong Core calls but does **not** prove real Unity signatures.
> It has **never been opened in Unity**. Open it once in Unity 6 and fix whatever the console reports.

## Open and run

1. `python -X utf8 Core/tools/sync_to_unity.py` - rebuilds the Core DLL and `catalog.json` (generated from `SPEC.md`) into
   `Assets/Plugins/TowerOfChaos/` and `Assets/Resources/`. (Those two outputs are git-ignored.)
2. Open `UnityClient/` with **Unity 6 (6000.0.x LTS)**. Unity Hub may ask to pick an installed 6000.0 editor: `ProjectVersion.txt` is a placeholder (`6000.0.23f1`).
3. *Project Settings > Player > Active Input Handling* must be **Input Manager (Old)** or **Both** (the slice uses the legacy `Input`; the HUD shows a warning otherwise).
4. Press **Play** in any scene (even the empty default): `TowerBootstrap` creates itself, the camera, a light, the hero and the HUD.
5. Optional: menu **Tower > Apply Project Settings (Android)** sets IL2CPP, ARM64 only, high stripping, landscape.

## Controls

| Action | Keyboard / mouse | Phone |
| :--- | :--- | :--- |
| Move | WASD / arrows, or drag on the left half | drag on the left half (floating joystick) |
| Attack | Space, or click right half | tap right half |
| Show golden path (debug) | G | - |
| Restart after win / elimination | R | tap right half |

## What you should see

* Start room is chosen by the start dice (1-6). Grey-box room from the Core generator: blue = entrance safe zone, dark red = permanent hazard, orange/yellow = trap tile,
  cyan = crossing aid, purple = portal, yellow ball = first-runner reward, red/purple capsule = monster (kill it to unlock the door), green/red cube = exit door.
* **Timed lanes** flash green (open) -> yellow (warning, 0.8 s) -> red + raised (blocked): deterministic from the match seed (`TrapClock`).
* Damage placeholders by tier (S0/A10/B20/C35); death -> room 1 of the same floor (3-5 s pause in room 1, else 2 s) with a 3 s shield; fog from `TowerRules` eliminates you permanently;
  the last room of the tower (floor `H`, room 10) is the crown room: stand in the altar circle for 8 s (damage resets it).
* `TowerBootstrap.TowerHeight` = 6 for v1.0, 10 for the full tower.

## Not in this slice

Other players and networking, real heroes/skills, monster AI, rewards/portals as gameplay (they are drawn but inert), art, audio, real UI (RTL Persian), URP
(the slice uses whatever default pipeline the project has; URP conversion is a follow-up task).
