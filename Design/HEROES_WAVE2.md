## ۰. قواعد طراحی این موج

* **فرمول هر هیرو:** ریشه ایرانی-اسطوره‌ای (§۲۶.۱ ستون ۴) **+** ژانر یکی از ۱۰ طبقه برج **+** یک سبک جهانی سوم. هر هیرو از یک طبقه «می‌آید» و مکانیک امضایش با همان طبقه بازی می‌کند (ولی در همه طبقه‌ها قابل‌بازی است).
* **مرجع حس:** خوانایی و تناسب ضخیم **Brawl Stars**، قدرت مهارت و `Cut-in` التیمیت **Mobile Legends**، عمق مکانیکی و اسطوره‌ای **Dota 2**. هیچ هیرویی کپی هیروی یک بازی دیگر نیست.
* **اعداد پایه (مثل §۱۰.۱):** `100 HP`، سقف `50 Shield`، سرعت `5.7–6.3 m/s`، حمله پایه `0.6s CD` و `25 DMG` به هیولا (استثنا فقط آرش)، دمیج به رقیب ≈ `8–11` در حمله پایه و `15–25` در مهارت. کول‌داون S1 بین `13–18s`، S2 بین `11–14s`، التیمیت با انرژی `0 → 100` (§۱۶.۳).
* **محدودیت‌های قطعی SPEC:**
  * هر اثر مختل‌کننده دید/کنترل **حداکثر ۶ ثانیه** + حالت `Reduce Effects`؛ چشمک‌زنی ≤ ۳ بار در ثانیه؛ جابجایی آیکون‌های HUD ممنوع (§۱۸.۲). هر هیرو قبل از انتشار از فهرست «انجام‌شده» §۱۸.۷ رد می‌شود.
  * هر شیء/دیواری که هیرو می‌سازد **موقت** است و از `PathPolicy` رد می‌شود: روی کاشی در، گلوگاه یک‌کاشی مسیر طلایی و دایره تاج قرار نمی‌گیرد (§۶.۱).
  * مهارت‌های جابجایی از دیوار، در بسته و مرز اتاق عبور نمی‌کنند.
* **رده سنی ۱۲+ و حساسیت فرهنگی:** خشونت کارتونی، بدون خون واقعی؛ بدون نماد مذهبی یا سیاسی؛ بدون صورت سیاه (`Blackface`؛ پس نه حاجی فیروز و نه سیاه‌بازی)؛ داستان ضحاک بدون جزئیات ترسناک اسطوره (مارها فقط شخصیت‌های بامزه و بدجنس‌اند).

## ۳. `H06` فرهاد (`Farhad`) — *کوه‌کن*

> **کلاس:** حفار · **خاستگاه:** طبقه ۱ (سیاه‌چال باستانی) · **سرعت:** `5.9 m/s` · **سختی:** ★★☆  
> **ترکیب سبک:** سنگ‌نگاره‌های بیستون + معدن‌کاوی دیزل‌پانک + شاعر عاشق (داستان شیرین و فرهاد)

| بخش | توضیح |
| :--- | :--- |
| **ظاهر و سیلوئت** | قوزدار و پرعضله، کلاه معدن با فانوس، کلنگ-مته غول‌پیکر روی پشت؛ شال بلند شاعرانه که پشت سرش تاب می‌خورد. سیلوئت: «علامت سؤال» (قوز + کلنگ بالای سر). |
| **رنگ‌ها** | اُخرایی سنگ، مس، فیروزه‌ای تیره + تأکید: کهربایی فانوس |
| **حمله پایه** | ضربه کلنگ، کمان ۳ متری، `25 DMG` هیولا / `10 DMG` رقیب. هر ضربه سوم یک شیء شکستنی (بشکه، ستون یخ، دیوار ترک‌دار) را می‌شکند. |
| **پسیو — سنگ‌خوان** | دیوارهای ترک‌دار، درپوش چاله‌های پنهان و مین‌های دفن‌شده در ۵ متری را با خط طلایی می‌بیند. `+50%` دمیج به هیولاهای سنگی و اشیای شکستنی. |
| **S1 — تونل بیستون** (`16.0s`) | ۱.۵ ثانیه زیر زمین می‌رود و تا ۷ متر جابجا می‌شود: **ایمن از تله‌های زمینی** (تیغ، چاله، کف آتشین، مین) و غیرقابل‌هدف. از زیر آب عمیق، اسید و دیوار عبور نمی‌کند. هنگام بیرون آمدن: پرتاب ۰.۶ ثانیه‌ای در شعاع ۲ متر (`-15 HP` رقیب، `40 DMG` هیولا). |
| **S2 — ستون شیرین** (`12.0s`) | یک ستون سنگی تک‌کاشی تا ۶ متر جلوتر برای ۵ ثانیه: جلوی گلوله، لیزر و بدن را می‌گیرد؛ با ۳ ضربه می‌شکند. |
| **التیمیت — کوه‌کنی** | در یک لحظه یک ترانشه مستقیم ۱۲ متری جلوی خود می‌کَند (۶ ثانیه): برای فرهاد تله‌های زمینی روی ترانشه خاموش‌اند و `+30%` سرعت دارد؛ برای رقبا ترانشه پر از آوار است (`-30%` سرعت). |
| **ضدبازی** | لیزر و تله‌های هوایی در تونل و ترانشه هم به او می‌خورند؛ ترانشه مستقیم و قابل پیش‌بینی است؛ ستون شکستنی است. |
| **یادداشت فنی** | ستون در هر بار استفاده از `PathPolicy` رد می‌شود (نه روی در، گلوگاه یا دایره تاج). ترانشه = پرچم «ایمنی از تله زمینی» روی کاشی‌ها فقط برای این بازیکن + یک `Decal`. ریسک: کم. |

**اسکین‌ها**

| سطح | نام | خط | ایده | چه چیزی عوض می‌شود |
| :--- | :--- | :--- | :--- | :--- |
| **Rare** | **فرهاد نوروزی** (`Nowruz Farhad`) | 🌱 نوروز | کوه‌کنی که برای سال نو سبزه کاشته | پالت سبز سبزه و قرمز؛ روبان قرمز گره‌خورده دور کلنگ؛ فانوس به تُنگ ماهی قرمز نورانی تبدیل می‌شود. |
| **Epic** | **حفار مریخ** (`Mars Driller`) | — | معدنچی فضایی در اولین معدن مریخ | کلاه فضانوردی و کوله اکسیژن (قطعه مدل جدید)؛ کلنگ ← مته لیزری؛ گرد و خاک تونل قرمز مریخی؛ ستون ← صخره مریخی با آنتن. |

## ۴. `H07` لُعبت (`Lobat`) — *عروسک‌گردان خیمه‌شب*

> **کلاس:** عروسک‌گردان · **خاستگاه:** طبقه ۲ (کارناوال دیوانه) · **سرعت:** `6.1 m/s` · **سختی:** ★★★  
> **ترکیب سبک:** خیمه‌شب‌بازی ایرانی + ریش‌سفید سیرک + اسباب‌بازی کوکی

| بخش | توضیح |
| :--- | :--- |
| **ظاهر و سیلوئت** | دختری بلندقد روی چوب‌پا با صلیب چوبی نخ‌های عروسک در دست؛ عروسکش **پهلوان پنبه** (یک پهلوان پارچه‌ای چاق و بی‌عرضه با سبیل نخی) همیشه دنبالش تلوتلو می‌خورد. سیلوئت: «بلند + کوتاه» (دو شخصیت کنار هم). |
| **رنگ‌ها** | قرمز پرده نمایش، زرد خردلی، بنفش + تأکید: نخ طلایی |
| **حمله پایه** | ضربه نخ تا ۶ متر، `25 DMG` هیولا / `8 DMG` رقیب. |
| **پسیو — پهلوان پنبه** | اولین آسیب تله در هر اتاق به‌جای لعبت به عروسک می‌خورد (عروسک با پف پنبه «بیهوش» می‌شود و در اتاق بعد برمی‌گردد). |
| **S1 — پرده اول!** (`15.0s`) | عروسک را تا ۸ متر پرتاب می‌کند؛ ۳ ثانیه هیولاهای ۵ متری فقط عروسک را می‌زنند و رقیبی که به آن ضربه بزند ۱.۵ ثانیه کاغذرنگی روی صورتش می‌ماند (تاری دید). |
| **S2 — پشت پرده** (`11.0s`) | لعبت و عروسک جایشان را عوض می‌کنند (حداکثر ۱۰ متر، فقط داخل همان اتاق) + ۰.۳ ثانیه آسیب‌ناپذیری. ترکیب S1 + S2 = ۱۸ متر جابجایی. |
| **التیمیت — نمایش کوکی** | ۵ ثانیه همه رقبای اتاق کلید کوکی پشتشان پیدا می‌کنند: فقط مستقیم حرکت می‌کنند، هر چرخش ۰.۵ ثانیه طول می‌کشد و سرعت حمله `-20%`. با `EMP Kit` پاک می‌شود. |
| **ضدبازی** | عروسک `40 HP` دارد؛ اگر نابود شود، S1 و S2 تا اتاق بعد غیرفعال‌اند. لعبت بدون عروسک ضعیف است. |
| **یادداشت فنی** | عروسک یک موجود همراه شبکه‌ای با هوش ساده است. التیمیت = محدودیت نرخ چرخش در `HeroSim` (قطعی و قابل‌تست در Core). ریسک: متوسط (هوش همراه). |

**اسکین‌ها**

| سطح | نام | خط | ایده | چه چیزی عوض می‌شود |
| :--- | :--- | :--- | :--- | :--- |
| **Rare** | **عروسک یلدا** (`Yalda Doll`) | 🍉 یلدا | نمایش شب یلدا برای مهمان‌ها | پالت انار و زرشکی؛ پهلوان پنبه لباس هندوانه می‌پوشد و یک دیوان حافظ کوچک در دست دارد. |
| **Epic** | **کوکی حلبی** (`Tin Wind-Up`) | 🪁 جعبه اسباب‌بازی | هر دو به اسباب‌بازی حلبی قدیمی تبدیل شده‌اند | لعبت با بدنه حلبی و کلید کوکی پشت (قطعه مدل)؛ عروسک ← ربات حلبی؛ نخ‌ها ← فنر؛ کاغذرنگی ← جرقه حلبی. |

## ۵. `H08` بختک (`Bakhtak`) — *کابوس سنگین*

> **کلاس:** کابوس · **خاستگاه:** طبقه ۳ (تیمارستان وحشت) · **سرعت:** `6.2 m/s` (شناور) · **سختی:** ★★☆  
> **ترکیب سبک:** افسانه بختک (موجودی که روی سینه خواب‌رفته می‌نشیند) + گوتیک ویکتوریایی + سایه‌بازی کاغذی

| بخش | توضیح |
| :--- | :--- |
| **ظاهر و سیلوئت** | کفن مخملی سنگین و آویزان که روی زمین می‌کشد، دو دست بلند و باریک، نقاب چینی ترک‌دار با یک چشم ماه‌گون. سیلوئت: «قطره وارونه» (سنگین پایین، باریک بالا). |
| **رنگ‌ها** | سیاه جوهری، بنفش کبود، سفید مهتابی بیمار + تأکید: درخشش قرمز چشم |
